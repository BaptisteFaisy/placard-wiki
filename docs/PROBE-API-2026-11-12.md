# Sonde API de la plateforme — mesures du 12 novembre 2026 (prototypes du §22)

> Complément **applicatif** de la purge mesurée en PR #65 : ici, on mesure ce
> que la plateforme permet VRAIMENT, en **lecture seule**, avec le jeton API
> Atlassian de l'utilisateur (Basic auth). Aucune écriture sur le site : les
> `DELETE` sont tentés sur des numéros de version inexistants, les
> téléchargements sont bornés.
>
> Site : `one-atlas-cndz.atlassian.net` · espace `PLACARDDEMO`
> (« Placard — démo SYNTHÉTIQUE », id 3833860) · seed : 16 pages, 12 pièces
> jointes, une page à 2 versions, un modèle.
>
> Rejouer : `node tools/probe-confluence-api.mjs` (lit `~/.atlassian-login` et
> `~/.atlassian-api-token`, jamais affichés ; sortie JSON ligne par ligne).

## 1. Les mesures

| Point §22 | Appel | Verdict mesuré |
|---|---|---|
| **P1** purge d'une version | `DELETE /wiki/rest/api/content/{id}/version/999999` (v1) | **400** — l'endpoint existe : « Version 999999 to delete must be less than the current version 1 and greater than or equal to 1 » (`data.authorized=false`) |
| **P1** | `DELETE /wiki/api/v2/pages/{id}/versions/999999` (v2) | **405** `METHOD_NOT_ALLOWED` — v2 ne purge pas, **v1 seulement** |
| **P2** pièces jointes | `GET /wiki/rest/api/content/{pageId}/child/attachment` | **200**, 12 pièces : `secret-9.env` (53 o, `text/plain`), `secret-10.env` (79 o), `cle-privee-3.pem` (321 o, `application/x-pem-file`)… **taille et mediaType par pièce** |
| **P2** | `GET /wiki/rest/api/content/{pageId}/child/attachment/{attachmentId}/download` | **200**, binaire rendu, **octets égaux à la taille annoncée** (29 o sur 29) |
| **P4** restrictions | `GET /wiki/rest/api/content/{id}/restriction/byOperation` | **200** — listes `user` et `group` **vides** : pas de restriction de lecture explicite |
| **P4** partage « anyone with the link » | `GET /wiki/rest/api/space/PLACARDDEMO/settings` | **200**, champs : `routeOverrideEnabled`, `isPdfExportNoCodeStylingOptedIn`, `editor`, `spaceKey` — **aucun drapeau de partage public** |
| **P4** | `GET /wiki/rest/api/content/{id}?expand=space` | **200**, `space` ne contient que `id/ari/key/alias/name/type/status` — **pas d'état « anyone with the link »** |
| **P6** whiteboards | `GET /wiki/rest/api/content/search?cql=type=whiteboard` | **200**, `results: []` — le type existe en CQL mais **rien ne remonte** |
| **P6** bases Confluence | `GET …/search?cql=type=base` | **400** `BadRequestException: Unsupported value for type` — **le type n'existe pas en CQL** |
| **P9** groupes | `GET /wiki/rest/api/group?limit=5` | **200** — groupes **système** listés (`confluence-users-…`, `confluence-guests-…`, `confluence-user-access-admins-…`) |
| **P9** groupes imbriqués | `GET /wiki/rest/api/space/{key}/permission` | **405** `METHOD_NOT_ALLOWED` — pas de lecture d'appartenances par l'API contenu |

## 2. Ce que ça change dans le produit

1. **La purge d'une version précise est POSSIBLE** (v1, et seulement si la
   version est strictement inférieure à la version courante). La §22 et le §9
   partaient de « probablement impossible depuis Forge » : la vérité mesurée est
   plus nuancée — l'endpoint v1 existe et purge ; ce qui échoue, c'est **la
   version courante** (elle ne peut pas être supprimée), **les droits**, et
   **v2**. Le repli « demande groupée à l'administrateur » reste donc le bon
   comportement pour ces trois cas, et il ne doit plus être le comportement
   *par défaut* (PR #65 porte cette correction côté app).
2. **Le binaire d'une pièce jointe se lit**, et la route est connue :
   `/content/{pageId}/child/attachment/{attachmentId}/download`. La famille 12
   (§7) peut donc travailler sur le **vrai contenu** des pièces — taille et
   mediaType d'abord, binaire ensuite. Ce qui reste « non lu » se limite aux
   pièces au-delà des limites de payload/bundle, et la raison doit être
   affichée (déjà le cas, §14).
3. **Le partage « anyone with the link » n'est pas exposed par l'API** : ni sur
   le contenu, ni dans les réglages d'espace. Le terme `public-share` (+10) du
   §8 ne peut donc pas être **mesuré** — il reste une **hypothèse conservatrice
   affichée comme telle**, et le produit doit le dire ainsi. C'est exactement le
   repli prévu au §22.
4. **Whiteboards et bases sont hors de portée de l'API contenu** (type `base`
   inconnu, `whiteboard` vide) : l'angle mort est **réel**, il doit être déclaré
   dans l'écran de couverture et porté par le certificat (PW-19, PW-29).
5. **Les groupes imbriqués ne se résolvent pas** par l'API contenu : la
   fourchette de lecteurs (« entre 340 et 1 200 personnes ») reste la seule
   réponse honnête, avec sa méthode affichée.
6. **Un piège de lecture** : `GET /wiki/rest/api/space?keys=PLACARDDEMO` **ignore
   le filtre** et renvoie les 13 espaces du site (le premier est « EO »). L'espace
   se prend par sa clé dans le chemin (`/space/PLACARDDEMO`) ou par `spaceKey=`.
   Une lecture qui fait confiance à `results[0]` peut donc scanner le mauvais
   espace — sans le signaler.

## 3. Ce que la sonde ne peut pas mesurer (donc reste à faire en situation)

- **Realtime ciblé sur l'auteur** (§22.5) et **`asUser()` en écriture** (§22.7)
  : ce sont des comportements du **runtime Forge** ; ils se mesurent avec
  l'app déployée et un vrai compte, pas depuis un script extérieur.
- **Extraction du texte d'un PDF/DOCX/XLSX dans le bundle** (§22.3) : c'est une
  question de *toolchain du bundle*, pas de droits d'API. La sonde montre que
  les pièces sont atteignables et leur type connu ; l'extraction reste à
  vérifier dans le runtime.
- **Le passage à l'échelle (50 000 pages)** (§22.8) : la chaîne live mesure déjà
  16 pages / 40 emplacements / ~29 s sur l'espace semé (§ « Chaîne live »), ce
  qui Extrapolation reste une extrapolation.

## 4. Reproduction

```bash
# jetons lus depuis ~/.atlassian-login (email, site) et ~/.atlassian-api-token
node tools/probe-confluence-api.mjs
```

Sortie : une ligne JSON par mesure (`etape`, `status`, extrait borné). Aucune
valeur de secret n'est imprimée : les seules valeurs venues du site sont des
**tailles**, des **mediaType**, des **noms de fichier du seed** et les premiers
octets d'une pièce factice.
